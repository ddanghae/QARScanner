# 24시간 방향 확률 전망 PRD

- 상태: 구현·검증 완료
- 작성일: 2026-08-26
- 대상: reversal / early / pump_fade 결과 공통 보조 전망

## 문제

기존 0~100점은 규칙 근거의 합이다. early의 `hitRate`도 개별 코인 확률이 아니라 점수 구간의
과거 급등 빈도다. 점수 70을 상승 확률 70%로 바꾸는 것은 근거가 없고 사용자를 오도한다.

사용자에게 필요한 질문은 “조건을 몇 개 만족했는가?”와 별도로 다음처럼 정의돼야 한다.

> 마지막 마감 4시간봉 이후 24시간 안에, 해당 마감가와 변동성에 맞춘 위·아래 경계 중 어느 쪽을 먼저
> 건드리는가? 둘 다 건드리지 않으면 횡보다.

## 성공 기준

- 기존 전략 점수와 독립된 모델이어야 한다.
- 상승·하락·횡보 세 범주는 서로 배타적이고 합이 100%여야 한다.
- 경계는 마지막 4시간 마감가 기준 `±clamp(1.5 × ATR14%, 2%, 8%)`, 기간은 마감 4시간봉 6개(24시간)로 고정한다.
- 같은 미래 봉에서 위·아래 경계를 모두 건드린 학습 표본은 선후를 모르므로 제외한다.
- 특징은 신호 시점까지의 4시간봉과 같은 시점까지의 BTC 4시간봉만 사용한다.
- 학습·검증·시험을 시간순 60/20/20으로 나누고 경계마다 24시간을 purge한다.
- 최종 시험에서 단순 클래스 기준선보다 나쁜 모델은 `ready=false`로 두고 UI에 숫자를 표시하지 않는다.
- 결과에는 기간, 가격 경계, 상승·하락·횡보 확률, 신뢰도, 학습 표본, 데이터 기준일,
  주요 입력과 한계를 함께 표시한다.
- TP/SL 도달률, 수익 확률, 자동 주문 신호로 표현하지 않는다.

## 데이터와 모델

- 데이터: Binance USDⓈ-M Futures 공개 4시간봉, 현재 `TRADING` 상태인 USDT 무기한 종목
- 최대 길이: 종목당 1,000봉(약 166일)
- 평가 간격: 하루 1회
- 입력: 코인 4h/24h/72h/14d 수익률, RSI14, EMA20/50 거리, ATR%, 상대 거래량,
  최근 20봉 범위 위치, BTC 24h/14d 수익률·EMA50 거리·ATR%
- 후보 모델: 다항 로지스틱, 움직임/방향 분리 로지스틱, Gaussian Naive Bayes, Extra Trees
- 선택: 검증 구간 log loss 최소 모델
- 최종 확인: 시험 구간 accuracy, log loss, Brier score, 확률 구간별 정확도

## 파이프라인 제약

- reversal과 early가 이미 가지고 있는 4시간봉을 재사용한다.
- pump_fade는 1시간 급등 필터를 통과한 후보에만 4시간봉을 추가 요청한다.
- BTC 4시간봉은 스캔당 한 번만 요청해 세 모드가 공유한다.
- BTC 또는 모델 입력이 부족해도 기존 스캔은 실패시키지 않고 확률만 `산출 보류`한다.
- 진행 중 캔들을 포함한 opt-in 결과는 신뢰도를 항상 `낮음`으로 내린다.

## 알려진 한계

- 현재 거래 중인 종목만 포함하므로 상장폐지 종목 생존편향이 있다.
- 약 166일은 여러 상승·하락·횡보 국면을 충분히 대표하지 못한다.
- 모든 종목-일로 학습하며, 세 스캐너의 통과 집합만으로 별도 보정한 모델은 아니다.
- 공개 캔들만 사용하므로 주문장, 체결 슬리피지, 펀딩 비용을 예측하지 않는다.
- 방향 경계 첫 도달 확률이지 TP/SL, 기대수익, 승률이 아니다.

## 검증 게이트

1. 특징 prefix 불변: 미래 봉 변경이 신호 시점 특징을 바꾸지 않는다.
2. 라벨 선후: 미래 봉만 읽고 같은 봉 양쪽 도달은 `ambiguous`로 제외한다.
3. 확률 합: 상승+하락+횡보가 반올림 후에도 정확히 100이다.
4. 데이터 부족·모델 불일치: 숫자를 만들지 않고 `available=false`다.
5. 최종 시험: 단순 다수결/기준 확률보다 나쁘면 배포 모델을 활성화하지 않는다.
6. 전체 기존 테스트와 브라우저 콘솔 검증을 통과한다.

## 최종 검증 결과

- 전체 표본 77,904건, 학습 45,691건, 검증 15,557건, 시험 15,093건
- 데이터 기준일 2026-08-25, 동일 봉 양쪽 경계 도달 376건 제외, 수집 실패 종목 0개
- 검증 log loss로 선택된 모델: 움직임/방향 분리 로지스틱
- 시험 accuracy 42.04%, 다수 클래스 기준선 41.38%
- 시험 log loss 1.0769, 학습 사전확률 기준선 1.0813
- 시험 Brier 0.6520, 기준선 0.6551, ECE 0.0258
- 승격 게이트 통과. 다만 기준선 대비 개선폭이 작으므로 `신뢰 낮음/보통` 중심의 보조 전망으로 사용한다.
- 라이브 reversal 스캔과 상세창 렌더링을 확인했고 브라우저 콘솔 오류는 없었다.
