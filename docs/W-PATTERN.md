# W 패턴 검증 필터 — 조사 및 구현 근거

조사일: 2026-10-03 (한국 시간). 대상: 15분봉·1시간봉 USDT 무기한 선물. 기존 사용자 조건인 `L2 ≥ L1`을 유지한다.

## 1. 자료에서 확인한 정의

- [StockCharts: Double Bottom Reversal](https://chartschool.stockcharts.com/table-of-contents/chart-analysis/chart-patterns/double-bottom-reversal): 전통적인 쌍바닥은 선행 하락 흐름, 비슷한 두 저점, 사이의 고점으로 구성된다. 저항 돌파 전에는 후보이며, 거래량 증가가 돌파를 뒷받침한다. 돌파한 저항이 지지 역할을 하는 재시험도 가능하다. 자료의 주·월 단위 기간과 퍼센트를 이 스캐너에 그대로 이식하지 않았다.
- [Fidelity: Identifying chart patterns transcript](https://www.fidelity.com/bin-public/060_www_fidelity_com/documents/learning-center/Transcript_Chart-patterns_v2.pdf): 봉 도중의 돌파, 종가, 복수 종가, 시간·가격 폭 등의 확인 방식은 신호 속도와 잘못된 신호 노출 사이의 선택이다. 따라서 최초 돌파와 검증 완료 시각을 구분한다.
- [Schwab / thinkorswim: Double Bottom](https://toslc.thinkorswim.com/center/reference/Patterns/Classic-Patterns/Double-Bottom.html): 두 저점과 하나의 중간 고점이라는 구조, 조기 돌파 문제, 선행 추세·횡보 맥락을 설명한다. 이 구현은 하락 후 반전형, 횡보형, 사용자 요청의 상승 중 W를 구분한다.
- [StockCharts: Bollinger Bands / W-Bottoms](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-overlays/bollinger-bands): 두 번째 가격 저점이 더 낮지만 밴드 상대 위치는 강해지는 변형도 다룬다. 이는 사용자 요청과 다르므로 저점 이탈을 허용하는 예외로 쓰지 않았다. 볼린저 밴드나 RSI 다이버전스를 모든 W의 필수 조건으로 추가하지 않았다.

## 2. 출처 원칙과 구현상 선택의 구분

**출처가 뒷받침하는 일반 원칙**: 두 저점이 구분돼야 함, 의미 있는 중간 반등, 맥락 확인, 저항 돌파, 거래량과 종가/시간 확인.

**이 프로젝트의 초기 휴리스틱**: 1.5 / 1 ATR 높이, 25% / 60% 저점 차이, 6봉 간격, 양쪽 길이 3배 제한, 1.3배 거래량, 50% 몸통, 상단 30% 종가, 1.5 ATR 상승 한도, 다음 1봉 확인. 이 수치들은 문헌상의 보편 법칙이나 백테스트 최적값이 아니다. 15분·1시간 설정 객체는 분리하되, 실제 검증 전까지 수치는 동일한 상대 기준을 적용한다. 프로필 분리가 성과 개선이나 최적화를 의미하지 않는다.

## 3. 계산과 결정 순서

1. L1 앞선 20봉에서 이후 2봉까지 확인된 최근 스윙 고점(하락 기간 최소 2봉, 하락 폭 최소 1.5 ATR)을 찾는다. 하락폭 65% 및 1 ATR 회복 시 관심 등록하며 첫 저점 시점 ATR을 고정한다. 두 번째 확정 저점은 이후 반등이 늦어도 후보로 보관한다. 해당 저점을 다시 깨면 재확인한다.
2. L2가 확인될 때 `L1 < 중간 고점 시각 < L2`, `L2 ≥ L1`을 만족하는 구조를 검사한다. 넥라인은 L1 다음 봉부터 L2 직전 봉까지의 최고가이다.
3. `H = 넥라인 − L1`, `D2 = 넥라인 − L2`, `gap = (L2 − L1) / H`. `H ≥ 1.5 ATR`, `D2 ≥ 1 ATR`. 하락·횡보형은 `gap ≤ 0.25`, 선행 상승형은 `gap ≤ 0.60`.
4. 선행 상승 맥락: 첫 V 이전 고점에서 종가가 EMA20 위이고, 그 EMA20이 5봉 전보다 0.25 ATR 넘게 높다. 아니면 L1 직전 두 개의 10봉 종가 평균을 비교해 뒤 구간이 0.5 ATR 넘게 낮으면 반전형, 나머지는 횡보형으로 표기한다. 이는 휴리스틱 분류이며 시장 추세의 절대적인 정의가 아니다.
5. 중간 고점 양쪽 길이는 각 2봉 이상, 비율 ≤ 3. 저점 간 ≥ 6봉. 추가 확정 저점은 `L1 + 0.35H` 이하이며 앞뒤 반등이 `max(1 ATR, 0.5H)` 이상일 때만 다중 저점으로 센다. 상승 다리 안의 작은 흔들림은 제외 사유가 아니다. 타겟 이후 세 번째 지지는 L2로부터 4봉 이상 떨어져 있고, 같은 지지 구역으로 되돌아오기 전 반등이 `max(1 ATR, 0.5H)` 이상이며, 다시 0.5 ATR 회복한 경우에만 제외한다.
6. 돌파는 기존처럼 `종가 > 넥라인 + 0.15 ATR`. 이때 거래량, 양봉 몸통, 종가 위치, 과도한 상승을 함께 검사한다. 거래량·몸통·종가 위치가 부족하면 검사 내역을 시도 기록에 보관하고 타겟으로 남긴다. 첫 실패부터 6봉, 실패 최대 3회까지 재시도한다. 이후 재시도는 넥라인 기준 재돌파 또는 직전 봉 고가보다 높은 강한 종가가 필요하다. 상승 한도 초과는 구조 불량과 구분한 MISSED(상승 과다)로 종료한다.
7. 통과한 첫 돌파는 타겟에 남기고 `돌파 확인 중` 이벤트를 기록한다. 다음 완성 봉이 넥라인 위에서 닫히고 상승 한도 이내일 때만 타점으로 승격한다. 타점은 **이 확인 봉의 실제 종가와 확인 시각**이다. 이전 돌파 가격으로 소급하지 않는다.
8. 먼저 첫 저점 이탈을 확인하고 그 뒤 돌파를 확인한다. 필터 적용 시 타점 이전 L2만 이탈하면 WATCH로 돌아가 최대 2회 재확인한다. L1은 절대로 낮추지 않으며 동일 봉에 타점으로 승격하지 않는다. 타점 이후에는 기존 L2 이탈 무효 규칙을 유지한다. 타점 이후 넥라인 − 0.15 ATR 아래 종가 복귀도 무효 이벤트로 기록하되 원래 타점 이벤트를 보존한다.

9. ENTRY 이후 6봉 안에서 저가가 넥라인 ±0.15 ATR 안에 있고, 넥라인 위 양봉 종가이며 상승 한도 이내일 때만 별도 RETEST 시각·종가를 기록한다. 최초 ENTRY 기록은 수정하지 않는다. 단순 종가 유지를 재지지라고 표시하지 않는다.
10. 종목·시간봉마다 최대 6개 후보와 12개 첫 저점 후보를 동시에 추적한다. 같은 L2를 공유하는 패턴은 단계·최신성·L1 순으로 대표 하나를 표시한다. 신규 후보 발굴 순위에서 빠져도 진행 중 후보가 있는 시간봉은 계속 조회한다. 상장 종료 종목은 제외한다. 최근 499개 완성 봉으로 조회·새로고침 계산 범위를 맞추고 메모리를 제한한다. 후보 목록은 현재 페이지 세션에 유지되며 재접속 시 다시 스캔한다.
11. 최신 완성 봉이 없으면 API 오류가 없어도 화면에 갱신 필요를 표시한다(봉 마감 후 7초 유예). 15분 카드의 1시간 EMA20 방향은 참고만 표시하며 W 판정이나 과거 이벤트에 반영하지 않는다.

눌림 구간 평균 거래량이 첫 하락 구간 평균의 1.2배를 넘는지는 경고만 한다. 다른 검사 실패를 가산점으로 상쇄하지 않는다. 체크리스트 통과 수를 승률로 표현하지 않는다.

## 4. 한계 및 검증 범위

필터는 불충분한 형태·약한 돌파를 걸러내는 규칙이다. 통과 이후 실패를 없앨 수 없다. 한 봉 확인은 15분/1시간의 지연을 추가하며, 거래량이 적어도 성공하는 돌파나 빠른 급등을 제외할 수 있다. 완성 봉 기준이라 진행 중 봉의 일시적 이탈은 봉 데이터가 확정된 뒤 반영된다.

자동 테스트는 합성 캔들의 상태 전이, 실패 예외, 과거 시점 계산을 검증한다. 실시간 동일 데이터에 대한 필터 전후 비교는 작동 확인이며 성과 입증이 아니다. 승률·기대값을 평가하려면 수수료·슬리피지·실제 체결 가능 가격을 포함해 기간을 분리한 과거 검증이 필요하다.

## 5. 후속 실증 검증

현재 변경은 누락을 만드는 상태 전이와 표시 의미를 보완한 것이다. 다음 단계는 15분·1시간별 실제 차트에 정상 W·실패 W·놓친 W를 라벨링하고, 시간을 순서대로 재생해 가짜 돌파 비율·정상 W 누락률·표시 지연을 비교하는 것이다. 각 필터 제거 비교와 별도 평가 기간을 사용한다. 수익률을 평가한다면 체결 가능 시점·수수료·슬리피지를 포함한다. 이번 변경에서 실제 승률이나 필터 최적값을 산출하지 않았다.

## 6. 타점 손절·익절 기준선

ENTRY 확인 봉의 종가를 E, 두 번째 저점을 L2라고 하면 손절 기준 SL=L2, R=E−SL이다. TP1=E+R, TP2=E+2R, TP3=E+3R로 계산한다. 타점 확정 순간에 저장하고 이후 가격으로 이동시키지 않는다. WATCH/TARGET에는 이 계획을 표시하지 않는다. RETEST는 해당 확인 종가를 기준으로 별도 계획을 만들며 최초 ENTRY 계획은 보존한다. 무효·만료 기록의 가격은 당시 계획으로 표시한다.

가격이 유한한 양수이고 SL<E인 경우에만 계산한다. 손절 변동률은 100R/E, 각 TP 변동률은 100nR/E이다. 이는 레버리지 수익률이나 순수익률이 아니며 수수료·슬리피지를 포함하지 않는다. 1R/2R/3R은 명시적 표시 규칙이고 최적화·성과 검증한 목표가가 아니다. 기존 넥라인 종가 이탈 및 저점 이탈 무효 규칙은 유지하므로, SL 가격 도달 전에도 패턴이 무효가 될 수 있다. 이 기능은 기준선 표시이며 주문 실행이나 봉 내 SL/TP 체결 순서·수익 실현 판정을 추가하지 않는다.
