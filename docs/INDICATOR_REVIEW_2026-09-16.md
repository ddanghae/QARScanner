# 지표 점검 및 보완 보고서

## 먼저 알아둘 점

현재 스캐너에는 추세·과열·거래량·구조전환·CRT 지표가 이미 있다. 이번 점검에서 우선 필요한 것은 지표 수를 늘리는 일이 아니라 **같은 시각의 완성된 가격으로 계산하고, 오래된 결과를 제때 내리는 것**이었다.

점검 대상은 QARScanner의 데이터 수집, 24시간 방향 확률, CRT + TBS, 상세 손익 설명이다. 전체 전략의 수익성을 새로 검증한 보고서는 아니다.

## 발견한 문제와 적용한 수정

| 우선순위 | 쉽게 설명한 문제 | 이번 수정 |
|---|---|---|
| 높음 | 마지막 봉을 무조건 버려서 완성된 최신 가격까지 빠질 수 있었다 | 실제 마감 시각으로 판정하고, 미래 봉과 시각 없는 자료는 제외 |
| 높음 | 저장해 둔 미완성 봉이 시간이 지나면 완성된 봉처럼 쓰일 수 있었다 | 캔들 마감 경계를 넘은 캐시는 폐기하고 최종 OHLC 재조회 |
| 높음 | 실시간 옵션을 켜면 아직 움직이는 봉으로 ‘마감 봉 기준’ 확률을 계산할 수 있었다 | 확률은 옵션과 관계없이 마감된 4시간 봉만 사용 |
| 높음 | 코인과 BTC의 시계가 다르거나 중간 봉이 없어도 확률이 나올 수 있었다 | 연속성·가격 유효성·최신성·양쪽 마감 시각 일치 검사. 문제 시 산출 보류 |
| 높음 | CRT 확인 표시가 재스캔 전까지 남아 있었다 | 시세 기준 5분, 신호 확인 후 15분, 기준 4시간 범위 교체 중 먼저 오는 기한에 만료. 목록·필터·열린 상세의 전용 계획도 갱신 |
| 중간 | 새 4시간 봉이 끝나도 이전 확률이 계속 보였다 | 기준 봉 교체 시 숫자를 내리고 재스캔 안내 |
| 중간 | 조기 포착에서 얻은 ‘37% → 49%’ 설명이 반등 전략에도 나왔다 | 공통 손익 화면은 실제 계산 가정만 설명. 특정 전략의 과거 승률을 다른 전략에 적용하지 않음 |

이는 가격 조건이나 승률을 더 유리하게 꾸미는 변경이 아니다. 같은 규칙을 더 정확한 입력과 시각으로 판단하도록 고친 것이다. 데이터 불일치 시 이전보다 ‘산출 보류’가 많아질 수 있다.

## 지표별 현재 평가

- **급락 반등:** 구조와 유동성 근거가 있지만 가중치 상당수는 경험적 설정이다. 높은 점수를 높은 성공 확률로 읽으면 안 된다.
- **조기 포착:** 과거 점수 구간별 검증 자료가 있다. 구간의 평균 결과이며 개별 코인이나 CRT 결합 조건의 승률은 아니다.
- **급등 후 급락:** 실험 규칙이다. 추가 데이터에서 비용 반영 손익 검증이 필요하다.
- **CRT + TBS:** 봉 이탈·복귀·전환 검출과 손절 계획을 제공한다. 기존 후보에 붙는 확인 기능이므로 모든 CRT 종목을 검색하는 독립 스캐너는 아니다. 승률은 미측정이다.
- **24시간 방향 확률:** 배포 모델의 시험 정확도는 약 42.04%, 단순 기준은 약 41.38%다. 개선 폭이 작으며 현재 학습 데이터는 2026-08-25까지다. 이번 변경은 입력 검증 개선이며 모델 재학습이나 예측력 향상을 입증한 것은 아니다.

## 앞으로 필요한 보완 — 이번 완료 범위와 구분

1. **CRT 및 급락 실험 전략의 시간순 백테스트.** 수수료·슬리피지 포함, 한 봉에 손절/목표가 함께 닿으면 모호 사례로 별도 집계. 규칙 조정 데이터와 마지막 시험 데이터를 분리해야 한다.
2. **시장 상황별 검증.** 상승장·하락장·횡보장에서 각각 표본 수, 평균 손익, 최대 낙폭을 비교한다. 거래가 적은 구간에 확률 숫자를 붙이지 않는다.
3. **확률 모델의 최근 구간 성능 추적.** 예측 당시 값을 저장한 뒤 24시간 결과와 대조해 확률 오차와 기준선 대비 개선을 감시한다. 재학습 모델은 별도 검증을 통과한 뒤 배포한다.
4. **CRT 전용 페이퍼 기록.** 현재 기록 버튼은 기존 전략의 계획을 저장한다. CRT 전략 평가에 사용하려면 전략 이름·확인 시각·범위·손절·목표를 독립적으로 보존하는 기록 방식이 필요하다.

이 네 항목은 추가 연구/기능 과제이며 이번 수정으로 검증됐다고 주장하지 않는다. 특히 좋은 결과를 만들기 위해 임의로 점수를 올리거나 확률을 더하지 않았다.

## 확인 방법

`node tests/run.js`로 전체 회귀 테스트를 실행한다. 마감 경계·캐시 재조회 조건·미완성 봉 배제·시각 불일치·중간 봉 누락·신호 만료·확률 만료가 새 검증 항목이다. `tests/crt-tbs-preview.html`의 ‘만료 동작 테스트’로 재스캔 없이 열린 상세에서 계획이 내려가는지 확인할 수 있다.

이번 실행 결과: **194/194 테스트 통과**, JS 구문 검사 및 변경 파일 공백 검사 통과. 브라우저에서 재스캔 없이 목록·열린 상세가 ‘신호 만료’로 바뀌고 CRT 전용 계획이 사라지는 것을 확인했다. Binance 공개 API의 BTC/ETH 4시간봉으로 실시간 옵션을 전달해도 마감 봉 확률만 산출되고 세 확률의 합이 100%임을 확인했다.
