# CRT + TBS 적용 규칙

기존 세 스캐너가 찾은 후보에 추가하는 확인 기능이다. 독립적으로 모든 CRT 종목을 찾는 네 번째 스캐너는 아니다. 전체 스캔에도 적용되며, 기존 점수·24시간 방향 확률·매매 기록의 원래 계획은 유지한다.

## 쉽게 보기

4시간 봉의 위아래를 상자라고 생각한다. 가격이 상자 아래에서 마감했다가 안으로 돌아오고, 5분 봉에서 위로 돌아서는 모습까지 보이면 LONG 확인이다. 위로 나갔다가 아래로 돌아서는 경우는 SHORT 확인이다.

목록의 `CRT + TBS 확인만`을 켜면 기존 후보와 CRT 방향이 같은 확인 신호만 남는다. 상세의 `CRT 전용 검토 가격`에서 기준가·손절·손실률·목표를 본다. 기존 `기록` 버튼은 원래 스캐너 계획을 기록하므로 CRT 전용 거래 기록으로 사용하지 않는다.

## 정확한 코드 규칙

- 기준 범위: 가장 최근 **마감된 4시간 봉** 고가/저가. 다음 4시간 봉 마감 시 교체. Binance UTC 봉 경계를 그대로 사용하며 별도 뉴욕 세션 제한은 없다.
- TBS: 기준 범위 밖에서 5분 봉 **종가** 마감. 꼬리만 이탈하거나 경계와 같은 종가는 제외한다.
- 복귀: 이탈 후 6개 5분 봉 이내에 범위 안에서 종가 마감.
- 전환: 복귀 이후 6개 봉 이내에 LONG은 복귀 봉 고가 위, SHORT는 복귀 봉 저가 아래에서 종가 마감. 복귀와 전환을 같은 봉에서 인정하지 않는다.
- 확인 후 15분까지만 유효. 화면은 마지막 스캔 당시 상태이며 자동 갱신 또는 재스캔으로 갱신한다.
- 양쪽 범위를 모두 이탈했으면 제외. 복귀 후 경계나 스윕 극단을 다시 잃으면 무효. 전환까지 이미 중앙 목표를 건드렸거나 확인 이후 중앙에 도달하면 추격 제외.
- 손절: 이탈~복귀 구간 극단 바깥에 전환 시점 5분 ATR14 × 0.25 여유. 최소 거리 0.5%. 현재 5분 마감 기준 손절 거리가 0.5~8% 밖이면 제외.
- 목표 1: 범위 중앙. 목표 2: 반대편 경계. 진입 검토 기준은 마지막 마감 5분 봉 종가.
- 목표 2 순손익비 = `(목표 거리 − 기준가 × 왕복비용) / (손절 거리 + 기준가 × 왕복비용)`. 기본 비용 0.2%, 최소 1.5. 레버리지 또는 부분 익절 자동 적용 없음.
- 마감 시각으로 진행 중/미래 봉을 제외하며 실시간 캔들 설정을 켜도 CRT 확인은 마감 봉만 사용. 누락·중복·오래된 데이터는 산출 보류.
- API: 분석 결과 후보의 4h/5m만 조회, 중복 심볼 합치기와 기존 캐시 재사용. 추가 요청 실패가 기존 후보를 제거하지 않음.

## 해석과 한계

이번 규칙은 자동 검출을 위해 시간 제한·ATR 여유·손익비 문턱을 명시한 **프로젝트의 실험 버전**이다. 모든 CRT/TBS 교육 방식과 동일하다는 뜻이 아니다. 패턴 검출과 회귀 테스트는 수익성 검증이 아니며, 이 결합 조건의 승률은 아직 없다. 기존 24시간 예측도 CRT를 학습한 모델이 아니므로 확인 시 확률을 높이지 않는다.
