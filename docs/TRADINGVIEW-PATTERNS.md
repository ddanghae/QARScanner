# TradingView에 스캔 패턴 표시

스캐너가 찾은 **선택 종목의 패턴 스냅샷**을 TradingView 차트에 표시합니다. 이 지표는 차트에서 패턴을 다시 추측하지 않고, 스캐너가 계산한 패턴명·시간봉·적합도·완성률·가격선을 그대로 사용합니다.

## 설치와 사용

1. [패턴 표시 지표 코드](../pine/qar_pattern_snapshot.pine)를 열어 전체 내용을 복사합니다.
2. TradingView 차트 하단의 **Pine Editor**에 붙여넣고 저장한 뒤 **차트에 추가**합니다. 기존 `qar_scanner_sync_indicator.pine`과는 별도의 지표입니다.
3. 마켓 스캐너에서 패턴 스캔을 실행하고, 원하는 종목 카드의 **표시 데이터 복사**를 누릅니다.
4. TradingView에서 같은 Binance 무기한 선물 종목을 열고, 지표 설정의 **스캔 데이터** 입력란에 붙여넣습니다. 기본 설정에서는 차트 시간봉과 일치하는 패턴만 표시하므로 5분·15분·1시간·4시간을 전환해 확인하세요. 설정에서 다른 시간봉도 함께 표시할 수 있습니다.
5. 스캔을 새로 실행하면 3~4단계를 반복합니다. 차트 지표의 기존 데이터는 자동으로 바뀌지 않습니다.

## 차트에 표시되는 것

- 탐색된 각 패턴의 이름, 방향, 상태, 적합도, 완성률과 탐지 봉 시각
- 가격선이 있는 패턴의 기준선·구조 무효화선·기계적 투영선, 하모닉의 PRZ
- 선택된 타점 후보의 정밀 진입 구간과 SL·TP1·TP2·TP3
- XABCD 또는 ABCD 피벗 좌표가 있는 하모닉의 연결선

캔들 패턴처럼 원래 가격선이 없는 결과에는 이름과 상태만 표시합니다. 플래그·삼각형 등 대부분의 패턴은 스캐너가 전체 윤곽 좌표를 저장하지 않으므로, 차트에는 탐지 라벨과 계산된 기준 가격선을 표시합니다. 이 연결선이나 가격선은 새 봉에 따라 자동 갱신되지 않습니다.

다른 종목의 차트에서는 데이터가 잘못 표시되지 않도록 지표가 종목 불일치를 알려줍니다. 진행 중 봉을 포함해 스캔했다면 지표 상단에도 그 사실을 표시합니다. 표시값은 조건부 참고 자료이며 주문을 내거나 수익을 보장하지 않습니다. TradingView Pine은 일반 웹페이지의 실시간 JSON을 직접 읽을 수 없으므로 이 방식은 수동 갱신 스냅샷입니다.
