# QAR 스캐너 개발 하네스

## 시작

저장소 루트에서 Node.js 20 이상으로 실행합니다.

```powershell
npm test
```

한 번에 JavaScript 문법 검사, 로컬 미리보기 서버의 공개 경로 검사, 앱 테스트, 보조 Node 테스트 러너를 실행합니다. 차트 패턴 모듈은 플래그·하모닉 등 고정 합성 캔들 회귀 사례도 포함합니다. 외부 시세를 내려받지 않으며 개인 API 키가 필요하지 않습니다.

## 명령

| 목적 | 명령 |
|---|---|
| 전체 검사 | `npm test` |
| JavaScript 문법 검사 | `npm run check` |
| 앱 회귀 테스트 | `npm run test:app` |
| 브라우저 테스트 목록의 Node 러너 검사 | `npm run test:runner` |
| 미리보기 서버 경로 검사 | `npm run test:preview` |
| 웹앱 미리보기 | `npm run serve` |

미리보기는 `http://127.0.0.1:8080`에서 열립니다. 포트를 지정하려면 `npm run serve -- 8081`처럼 실행합니다. 서버는 앱 정적 파일과 사용자용 `docs/CHART-PATTERNS.md`만 제공합니다. 연구 자료, Git 메타데이터, 프로젝트 지침은 반환하지 않습니다.

## CI

GitHub Actions가 push와 pull request마다 `npm test`를 실행합니다. 네트워크 기반 백테스트와 장시간 데이터 수집은 기본 CI에 넣지 않습니다.

## 신호 변경 시 확인할 점

- 신호 시각 이전에 확정된 봉만 참조해 미래 데이터 누출을 막습니다.
- 후보 탐지, 진입·손절·익절, 포지션 규모, 주문 실행의 책임을 분리합니다.
- 패턴별 탐지 결과에 이름, 방향, 근거, 만료 시점을 남깁니다.
- 평가 구간 결과에 맞춰 규칙을 조정하지 않고, 미검증 성과를 확정적으로 표현하지 않습니다.
