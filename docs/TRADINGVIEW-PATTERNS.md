# TradingView 패턴 지표

## 차트에서 패턴 직접 감지

1. [멀티 시간봉 패턴 탐지 지표](../pine/qar_pattern_detector.pine)를 열어 전체 코드를 복사합니다.
2. TradingView 차트의 **Pine Editor**에 붙여넣고 저장한 다음 **차트에 추가**합니다.
3. 입력 설정에서 감지할 5분·15분·1시간·4시간 시간봉을 선택합니다. 기본값은 모두 켜져 있습니다.
4. 차트 우측 패널에서 시간봉별 롱·숏 개수, 패턴명, 적합도, 완성률을 확인합니다. 알림 메뉴에서는 상승·하락 패턴 알림을 따로 만들 수 있습니다.

각 시간봉은 그 시간봉의 캔들로 독립 계산됩니다. 현재 차트가 4시간보다 짧으면 `request.security()`를, 더 길면 `request.security_lower_tf()`를 사용해 낮은 시간봉의 봉도 따로 읽습니다. 결과는 확정된 시간봉 봉을 기준으로 표시합니다. 피벗형 구조는 설정한 깊이만큼 오른쪽 봉이 지나야 확정되므로 탐지에 지연이 생길 수 있습니다.

## 감지하는 패턴

- 지속형: 상승·하락 플래그와 페넌트, 상승·하락·대칭 삼각형, 상승·하락 쐐기, 직사각형 박스, 컵 앤 핸들 및 역컵 앤 핸들
- 반전형: 이중·삼중 천정과 바닥, 헤드앤숄더와 역헤드앤숄더
- 하모닉: 가틀리, 배트, 얼터네이트 배트, 버터플라이, 크랩, 딥 크랩, 샤크, AB=CD
- 캔들: 상승·하락 장악형, 망치형, 유성형, 샛별형, 저녁별형

차트에는 새 패턴이 나타날 때 시간봉 표시가 붙고, 패턴 목록과 점수는 우측 패널에 표시됩니다. 점수는 형태 적합도이며 과거 성과로 검증된 승률이 아닙니다. Pine판은 패턴 탐지를 차트에서 독립 실행하기 위해 브라우저 스캐너 규칙을 옮긴 것이므로 거래소 데이터 차이와 일부 도형 계산 방식에 따라 브라우저 스캐너 결과와 점수가 다를 수 있습니다. 피벗 깊이는 두 지표에서 맞춰 비교하세요.

## 스캐너 계산 결과를 차트에 옮길 때

스캐너가 계산한 진입 후보와 SL·TP를 그대로 보려면 기존 [스냅샷 표시 지표](../pine/qar_pattern_snapshot.pine)를 사용하세요.

1. 지표를 Pine Editor에 추가합니다.
2. 마켓 스캐너에서 패턴 검색 후 원하는 종목 카드의 **표시 데이터 복사**를 누릅니다.
3. 같은 종목 차트의 지표 설정에서 **스캔 데이터**에 붙여넣습니다.

스냅샷은 복사 당시 값이므로 새 검색 뒤 다시 붙여넣어야 합니다. TradingView Pine이 임의의 웹사이트 실시간 JSON을 가져오는 기능은 제공하지 않으므로, 차트 자체 감지와 스캐너 결과 복사는 각각 별도 지표로 동작합니다. [TradingView 다중 시간봉 데이터 문서](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/), [확정값과 리페인팅 문서](https://www.tradingview.com/pine-script-docs/concepts/repainting/)
