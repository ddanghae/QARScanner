# QARScanner 스캔 기록·성과 PRD

- 승인일: 2026-08-24
- 상태: 승인 및 구현
- 범위: 세 스캔 모드 공통 forward paper 기록

## 문제

스캔 결과가 새로고침 뒤 사라져 어떤 코인이 반복 포착됐는지, 포착 이후 가격이 방향대로
움직였는지 확인할 수 없다. QARScanner는 주문 시스템이 아니므로 실제 매수·포지션 기록이
아닌 신호 사건과 이후 가상 성과를 투명한 기준으로 남겨야 한다.

## 성공 기준

- 성공 스캔의 최종 후보를 브라우저에 보존하고 반복 포착을 한 사건으로 묶는다.
- 코인, 모드, 방향, 최초·최근 시각, 반복 횟수, 점수, 단계와 1h/6h/24h 방향 수익률을 표시한다.
- 24h MFE/MAE와 당시 TP1·손절 계획의 선도달 결과를 표시한다.
- 임시·대기·불완전·모호한 표본과 성과 분모를 명시적으로 구분한다.
- 필터, JSON/CSV 내보내기와 확인 절차가 있는 기록 삭제를 제공한다.

## 범위

- 버전된 localStorage 키, 최대 500개 사건, 6시간 episode dedup
- 공개 Binance USDⓈ-M 5분봉 범위 조회
- 급락 반등, 조기 매집, 급등 후 급락 세 모드 공통 기록 화면
- 다음 5분봉 가상 진입과 1h/6h/24h checkpoint, 24h MFE/MAE, TP1/stop outcome

## 제약과 비범위

- 백엔드, 계정·API 키, 실제 주문, 기기 간 동기화는 추가하지 않는다.
- 적용 전 저장되지 않은 과거 스캔은 재구성하지 않는다.
- 수수료, 펀딩, 슬리피지, 포지션 크기와 겹치는 포지션을 반영하지 않는다.
- 자본 배분 모델이 없으므로 누적 계좌 수익곡선을 만들지 않는다.

## 인과성과 실패 처리

- `detectedAt`은 성공 스캔 완료 시각이며 가상 진입은 그보다 엄격히 뒤인 첫 5분 경계의 시가다.
- 성숙한 checkpoint까지 연속된 마감 5분봉만 사용한다. 포착 이전·진행 중·미래 봉은 제외한다.
- 5분봉 공백·형식 오류는 `INCOMPLETE`, 같은 봉의 TP1·손절 동시 접촉은 `AMBIGUOUS`다.
- 확정된 가상 진입가, checkpoint와 계획 결과는 이후 원시 데이터로 덮어쓰지 않는다.
- 임시 캔들 신호, pending, incomplete, ambiguous, invalid는 해당 성과 분모에서 제외한다.

## 구현·검증 계획

1. Builder: 순수 계산, 저장소, 범위 API, 컨트롤러와 기록 UI를 구현한다.
2. Auditor: lookahead, repaint, leakage, 중복 편향, 분모와 저장 실패를 검토한다.
3. Tester: 경계 시각, LONG/SHORT, prefix 불변, 결측, 동일 봉, 보관 상한과 전체 회귀를 검증한다.
4. Integrator: 문서와 서비스워커를 갱신하고 전체 테스트 통과 뒤 커밋한다.
