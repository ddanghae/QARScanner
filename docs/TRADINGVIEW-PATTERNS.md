# TradingView 패턴 지표

## 설치와 사용

1. [멀티 시간봉 패턴 탐지 지표 코드](https://raw.githubusercontent.com/ddanghae/QARScanner/main/pine/qar_pattern_detector.pine)를 열어 전체 코드를 복사합니다.
2. TradingView 차트의 **Pine Editor**에 붙여넣고 저장한 다음 **차트에 추가**합니다.
3. 입력 설정에서 감지할 5분·15분·1시간·4시간 시간봉을 선택합니다. 기본값은 모두 켜져 있습니다.
4. 결과 패널에서 시간봉별 롱·숏 개수, 감지된 패턴, 적합도, 완성률을 확인합니다. TradingView 알림 메뉴에서 상승·하락 패턴 알림을 따로 설정할 수 있습니다.

## 시간봉 처리

각 시간봉은 해당 시간봉의 캔들로 독립 계산됩니다. 5분·15분·1시간·4시간 감지 결과는 현재 차트 시간봉을 바꿔도 패널에서 각각 확인할 수 있습니다. 차트보다 낮은 시간봉은 TradingView의 하위 시간봉 요청 기능으로 읽고, 결과는 확정된 봉 기준으로 표시합니다. 피벗형 구조는 설정한 깊이만큼 오른쪽 봉이 지난 후 확정되므로 감지 시점이 늦어질 수 있습니다.

## 감지 패턴

- 지속형: 상승·하락 플래그와 페넌트, 상승·하락·대칭 삼각형, 상승·하락 쐐기, 직사각형 박스, 컵 앤 핸들 및 역컵 앤 핸들
- 반전형: 이중·삼중 천정과 바닥, 헤드앤숄더와 역헤드앤숄더
- 하모닉: 가틀리, 배트, 얼터네이트 배트, 버터플라이, 크랩, 딥 크랩, 샤크, AB=CD
- 캔들: 상승·하락 장악형, 망치형, 유성형, 샛별형, 저녁별형

새 패턴이 나타나면 차트에 시간봉 표식이 붙고 상세 목록은 결과 패널에 표시됩니다. 점수는 형태 적합도이며 승률이나 성공 확률이 아닙니다. Pine 지표는 브라우저 스캐너와 같은 패턴 계열을 각 시간봉에서 독립 감지합니다. 가격 공급자별 캔들 차이와 일부 도형 계산 방식의 차이로 스캐너 결과·점수와 완전히 같지 않을 수 있습니다. 비교할 때 같은 종목, 거래소, 시간봉, 피벗 깊이를 사용하세요.

TradingView Pine의 시간봉 요청은 상위 시간봉에 `request.security()`, 하위 시간봉에 `request.security_lower_tf()`를 사용합니다. 미확정 봉이 나중에 바뀌는 현상을 줄이기 위해 직전 확정 봉 값을 처리합니다. 자세한 내용은 [TradingView 다중 시간봉 데이터 문서](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/)와 [확정값·리페인팅 문서](https://www.tradingview.com/pine-script-docs/concepts/repainting/)를 참고하세요.
